# Instagram Pending Requests Canceler

Cancel all your pending Instagram follow requests in bulk with human-like behavior to avoid detection.

**What does this tool do?**  
Over time, you may have sent hundreds of follow requests that are still pending. Instagram doesn't provide a way to bulk cancel these requests, nor does it even show you a list of your pending requests. You have to manually remember and visit each profile one by one to cancel. This tool automates that process by using your exported Instagram data to find and cancel all your pending follow requests that have been waiting for days, weeks, or even months.

**Why would you need this?**
- Clean up hundreds of old pending requests you don't even remember sending
- Start fresh with your follow requests
- Remove requests from inactive or private accounts
- Save hours of manual work
- See exactly who you've sent requests to (Instagram doesn't show this)

### Installation

1. Clone the repository, or download it with **Code** → **Download ZIP** on GitHub and extract it
```bash
git clone https://github.com/mobilteknolojileri/instagram-pending-requests-canceler.git
cd instagram-pending-requests-canceler
```

2. Install required packages

Windows:
```bash
pip install -r requirements.txt
```

macOS (use `python3` and a virtual environment):
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

No separate browser download is needed. The script connects to your own Chrome.

### How to Get Your Instagram Data

1. Open Instagram on web browser
2. Go to **Settings** → **Accounts Center**
3. Select **Your information and permissions**
4. Click on **Download your information** 
5. Select your Instagram account
6. Choose **Download or transfer information** → **Some of your information**
7. Select **Followers, following and follow requests**
8. Set date range to **All time**
9. Format: **JSON**
10. Submit request and wait for download link (usually takes a few minutes)

After downloading and extracting, you'll find your data in a folder structure like:
```
instagram-yourusername-2025-10-23-[random-id]/
└── connections/
    └── followers_and_following/
        └── pending_follow_requests.json
```

Note: The folder name contains your username, date, and a random ID generated by Instagram.

### Usage

1. Launch Chrome in debug mode

Windows: get your Chrome user agent from [https://iplogger.org/useragents/](https://iplogger.org/useragents/), put it into `launch_chrome.bat` and run it:
```batch
--user-agent="YOUR_USER_AGENT_HERE"
```
```bash
launch_chrome.bat
```

macOS: skip the user agent step and run:
```bash
bash launch_chrome.sh
```

2. Login to Instagram in the opened Chrome window

3. Run the script (on macOS, run `source .venv/bin/activate` first if you opened a new terminal):
```bash
python cancel_requests.py
```

4. Enter the path to your `pending_follow_requests.json` file when prompted. You can drag the file into the terminal window and press Enter.

### How It Works

The script performs the following actions for each pending request:
1. Navigates to user profile
2. Clicks "Requested" button (detects button in any language)
3. Selects "Unfollow" option
4. Implements random delays between actions
5. Takes breaks every 20 and 50 users

### Safety Features

- 2-3 seconds delay between each user
- 20-30 seconds break every 20 users
- 60-90 seconds break every 50 users
- Random waiting to mimic human behavior
- Uses existing Chrome session to maintain cookies and session

### Notes

- Keep Chrome window visible during operation
- Don't interact with the browser while script is running
- Processing time approximately 20-25 minutes per 500 users
- Works with Turkish, English, French, Spanish, Italian, and German Instagram interfaces

Not: Klasör adı kullanıcı adınız, tarih ve Instagram'ın oluşturduğu rastgele bir ID içerir.
